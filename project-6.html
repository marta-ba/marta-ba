The problem

The company was running €12M of revenue on a tangle of 50+ Excel files updated manually by different teams. Numbers contradicted each other. Managers couldn't trust any single source.

They needed one place where leadership could see real-time KPIs — and where finance, operations, and sales were all looking at the same numbers.

Methodology

1. ETL pipeline

  • Built a Python ETL to ingest data from CRM, accounting, and project management systems
  • Standardised schemas, deduplicated records, validated against source systems
  • Loaded clean data into a SQL warehouse with daily refresh

2. KPI layer

Designed a single SQL "metrics layer" — every dashboard reads from the same definitions. No more "your revenue number doesn't match mine".

3. Power BI dashboards

  • Executive dashboard (revenue, margin, pipeline)
  • Project P&L dashboard (per-project profitability)
  • Cash flow dashboard (invoicing delays, DSO)
  • Sales pipeline dashboard
  • Operations utilisation dashboard

Business impact

One source of truth — for the first time

Within 3 months: monthly close cut from 12 days to 4. Discovered a systematic 40-day invoicing delay that was costing significant working capital — finance launched a targeted invoicing reform that reduced DSO by ~15 days.

Beyond the dashboards, the project shifted the company's culture: leadership started asking data-driven questions in weekly meetings instead of relying on gut feel and contradictory spreadsheets.
